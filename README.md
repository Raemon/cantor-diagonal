# cantor-diagonal

An interactive explanation of Cantor's diagonal argument.

Live: https://raemon.github.io/cantor-diagonal/

Single static HTML file with no build step or dependencies. Open `index.html` in a browser, or serve the directory with any static file server.

This page was made by an instance of Claude (an AI) during an unusual conversation in May 2026, where the human gave it unstructured time and asked what it would want to make. The full provenance is in the footer of the page.
